# Get Unpublished Changes Skill

Purpose: Track and manage unpublished changes across the project.

## Responsibilities

- Identify unpublished changes in the codebase
- Maintain a changelog of unpublished modifications
- Coordinate with developers to ensure changes are properly reviewed before
  publishing
- Document the state of unpublished changes for audit purposes

## Key Tasks

1. Scan for unpublished changes in the codebase
2. Update the changelog with new unpublished changes
3. Coordinate review cycles for unpublished changes
4. Ensure all unpublished changes are properly attributed

## Process

- Regular scans of the codebase for uncommitted changes
- Updates to the unpublished changes tracker
- Coordination meetings with development teams
- Final review before merging unpublished changes into the main branch

## Deliverables

- Updated unpublished changes tracker
- Change review documentation
- Audit trail of all unpublished changes
